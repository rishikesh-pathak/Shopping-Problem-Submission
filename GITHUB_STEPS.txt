BEFORE PUBLISHING
1. Extract this ZIP to a permanent folder. The folder containing Dockerfile is the repository root.
2. Install/open GitHub Desktop: https://desktop.github.com/
3. In GitHub Desktop choose File > Add Local Repository; if prompted to create a repository here, accept.
4. Publish Repository. UNCHECK "Keep this code private". The competition requires PUBLIC.
5. Copy the repository URL and commit SHA. Use SHOW_COMMIT_HASH.bat if Git is on PATH; or in GitHub Desktop History right-click commit and copy SHA.
6. Open the Databricks Shopping Sessions submission page, choose your team and enter the repo and commit.
7. Check scoring feedback for correctness, memory and official run time. Send a screenshot to ChatGPT.
IMPORTANT: Do not upload data, downloaded answers or generated 1M-event CSVs.
